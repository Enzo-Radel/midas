# 03 — Editar um gasto

**Status:** pendente · **Atualizada em:** 2026-11-05
**Depende de:** etapa 02

## O que esta etapa entrega
Cada gasto da lista ganha a ação de editar, que abre o cadastro com os dados atuais para corrigir.

## Critérios de aceite
- [ ] Da lista, a ação editar abre o cadastro com os dados atuais do gasto.
- [ ] Alterações salvas aparecem na lista, e o gasto muda de dia quando a data é alterada.
- [ ] Os totais dos dias afetados são atualizados.
- [ ] As mesmas regras de validação do cadastro valem na edição.
- [ ] Cancelar a edição não altera o gasto.
- [ ] A tela é confortável de usar no celular.

## Fora desta etapa
- Editar categoria e tags (entram nas etapas 05 e 06).
