# 01 — Cadastrar um gasto

**Status:** pendente · **Atualizada em:** 2026-11-05
**Depende de:** nenhuma

## O que esta etapa entrega
Passa a existir a tela de novo gasto, em que basta informar o valor para salvar. A data vem com hoje e a descrição é opcional. O gasto salvo aparece numa lista simples, do mais recente para o mais antigo.

## Critérios de aceite
- [ ] Dá para salvar um gasto informando só o valor; a data vem preenchida com hoje.
- [ ] Ao abrir o cadastro, o foco vai direto para o campo de valor.
- [ ] A data pode ser alterada para um dia passado ou futuro, e o gasto é salvo com a data escolhida.
- [ ] A descrição é opcional e, quando informada, é salva com o gasto.
- [ ] O sistema não aceita salvar sem valor, com valor zero ou negativo, nem sem data, e mostra o motivo.
- [ ] Cancelar ou voltar no meio do cadastro não salva nada.
- [ ] Depois de salvar, o gasto aparece na lista, que mostra do mais recente para o mais antigo.
- [ ] Gasto sem descrição aparece na lista com um texto neutro (ex.: "Sem descrição").
- [ ] A tela é confortável de usar no celular.

## Fora desta etapa
- Separadores por dia e total do dia (etapa 02).
- Categoria e tags (etapas 05 e 06).
