# 10 — Gerenciar favoritos

**Status:** pendente · **Atualizada em:** 2026-11-05
**Depende de:** etapa 09

## O que esta etapa entrega
Na lista de favoritos, cada favorito pode ser renomeado, ter os dados editados e ser removido.

## Critérios de aceite
- [ ] É possível renomear um favorito.
- [ ] É possível editar descrição, valor, categoria e tags de um favorito, e repetições futuras usam os novos dados.
- [ ] É possível remover um favorito, com confirmação.
- [ ] Nenhuma dessas ações altera gastos já cadastrados.
- [ ] A tela é confortável de usar no celular.
