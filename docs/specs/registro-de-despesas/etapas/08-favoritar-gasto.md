# 08 — Favoritar um gasto

**Status:** pendente · **Atualizada em:** 2026-11-05
**Depende de:** etapa 07

## O que esta etapa entrega
Passa a ser possível favoritar um gasto no cadastro, na edição ou direto da lista. O favorito é uma cópia independente dos dados do gasto (descrição, valor, categoria, tags).

## Critérios de aceite
- [ ] No cadastro (inclusive vindo de repetir) existe a opção favoritar, e salvar com ela marcada cria o favorito.
- [ ] Na edição e na lista é possível favoritar um gasto já cadastrado.
- [ ] Um gasto já favoritado aparece como tal, e favoritá-lo de novo não cria um favorito duplicado.
- [ ] É possível desfavoritar a partir do gasto que deu origem ao favorito.
- [ ] Editar ou excluir o gasto de origem não altera nem remove o favorito.
- [ ] O nome do favorito começa sendo a descrição; sem descrição, ele é identificado pelo valor e pela categoria.
- [ ] A tela é confortável de usar no celular.

## Fora desta etapa
- A lista de favoritos para repetir (etapa 09).
