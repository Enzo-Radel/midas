# 09 — Lista de favoritos para repetir

**Status:** pendente · **Atualizada em:** 2026-11-05
**Depende de:** etapa 08

## O que esta etapa entrega
Passa a existir a lista de favoritos, acessível a partir da tela inicial. Tocar num favorito abre o cadastro preenchido com os dados dele e a data de hoje.

## Critérios de aceite
- [ ] A lista de favoritos é acessível a partir da tela inicial.
- [ ] Tocar num favorito abre o cadastro com os dados dele e a data de hoje, e nada é salvo até a pessoa confirmar.
- [ ] Qualquer campo pode ser alterado antes de salvar, sem alterar o favorito.
- [ ] Com a lista vazia, aparece uma mensagem explicando que dá para favoritar a partir de qualquer gasto.
- [ ] A tela é confortável de usar no celular.
