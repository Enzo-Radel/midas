# 14 — Excluir categoria em uso com troca

**Status:** pendente · **Atualizada em:** 2026-11-05
**Depende de:** etapa 13

## O que esta etapa entrega
Ao excluir uma categoria com gastos, além de desativar, passa a ser possível excluí-la escolhendo outra categoria ativa, ou nenhuma, para os gastos e favoritos que a usavam.

## Critérios de aceite
- [ ] Ao tentar excluir uma categoria com gastos, o sistema informa quantos gastos a usam e oferece também excluir com troca.
- [ ] Na troca é possível escolher outra categoria ativa ou "sem categoria".
- [ ] Confirmando, a categoria some e todos os gastos e favoritos que a usavam passam para a escolhida.
- [ ] Cancelando, nada muda.
