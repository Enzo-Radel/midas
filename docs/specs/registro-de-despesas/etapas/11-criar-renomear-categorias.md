# 11 — Criar e renomear categorias

**Status:** pendente · **Atualizada em:** 2026-11-05
**Depende de:** etapas 05, 08

## O que esta etapa entrega
Passa a existir uma tela de categorias em que é possível criar novas e renomear as existentes.

## Critérios de aceite
- [ ] É possível criar uma categoria, que passa a aparecer para escolha nos gastos.
- [ ] É possível renomear uma categoria, e o novo nome aparece nos gastos e favoritos que a usam.
- [ ] Não é possível criar nem renomear para um nome igual a outro já existente, sem diferenciar maiúsculas de minúsculas, e o motivo é mostrado.
- [ ] A tela é confortável de usar no celular.
