# 06 — Tags no gasto

**Status:** pendente · **Atualizada em:** 2026-11-05
**Depende de:** etapa 03

## O que esta etapa entrega
O gasto pode ter várias tags. Elas começam vazias e são criadas digitando o nome na hora de atribuir.

## Critérios de aceite
- [ ] Na primeira vez não existe nenhuma tag.
- [ ] No cadastro e na edição é possível atribuir várias tags, ou nenhuma.
- [ ] Digitar um nome que ainda não existe cria a tag e a atribui ao gasto.
- [ ] Ao digitar, as tags existentes podem ser escolhidas.
- [ ] Não é criada tag com nome igual a outra já existente, sem diferenciar maiúsculas de minúsculas; a existente é usada.
- [ ] As tags do gasto aparecem na lista.
- [ ] É possível retirar uma tag de um gasto na edição.
- [ ] A tela é confortável de usar no celular.

## Fora desta etapa
- Renomear e excluir tags (etapa 15).
