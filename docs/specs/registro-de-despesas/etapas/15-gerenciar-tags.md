# 15 — Gerenciar tags

**Status:** pendente · **Atualizada em:** 2026-11-05
**Depende de:** etapas 06, 08

## O que esta etapa entrega
Passa a existir uma tela de tags em que é possível renomear e excluir tags.

## Critérios de aceite
- [ ] É possível renomear uma tag, e o novo nome aparece nos gastos e favoritos que a têm.
- [ ] Não é possível renomear para um nome igual a outra tag, sem diferenciar maiúsculas de minúsculas.
- [ ] É possível excluir uma tag, com confirmação; ela é apenas retirada dos gastos e favoritos que a tinham.
- [ ] A tela é confortável de usar no celular.
