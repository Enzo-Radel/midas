# 07 — Repetir um gasto

**Status:** pendente · **Atualizada em:** 2026-11-05
**Depende de:** etapas 05, 06

## O que esta etapa entrega
Cada gasto da lista ganha a ação de repetir, que abre o cadastro preenchido com os dados daquele gasto e a data de hoje.

## Critérios de aceite
- [ ] Da lista, a ação repetir abre o cadastro com descrição, valor, categoria e tags do gasto, e a data de hoje.
- [ ] Nada é salvo até a pessoa confirmar.
- [ ] Qualquer campo pode ser alterado antes de salvar.
- [ ] Salvar cria um novo gasto; o gasto original não muda.
- [ ] Cancelar não cria nada.
- [ ] A tela é confortável de usar no celular.
